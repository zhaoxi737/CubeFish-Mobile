方块鱼 使用说明

1. 为什么还要「登录」？能离线吗？

能。Minecraft 启动器需要知道玩家名，所以一定要选一种登录方式，两者选一个就行：

① 本地登录（离线账号） —— 不需要微软账号，随便起个名字就能玩：

适合：单人游戏、局域网联机、自己玩模组。名字要求 3–16 位，只能是英文字母、数字、下划线。

② 微软账号登录 —— 需要正版 Minecraft：

适合：进正版服务器、用正版皮肤/披风。流程是「浏览器打开链接 → 输入设备码 → 授权」。

第一次打开 App 会看到「登录方式」页面：上面是微软登录，下面的本地登录/离线账号就是免正版那条。已经进过的话，主界面右上角的账户区域可以「添加账户」再选离线。

2. 怎么安装游戏版本（第一次玩必看）

  1. 主界面最上面那一行大按钮（显示「启动游戏 / 开始游戏」的那个）上方有一条灰色的版本栏，显示当前选择的版本（没装过会显示 Select a version / 选择版本）。
  2. 点这条版本栏 → 弹出「创建配置」页面。
  3. 先选类型：原版（Vanilla） 就是纯净生存；想玩模组选 Fabric / Forge 那类。
  4. 接着选 Minecraft 版本（例如 1.21.1）→ 点「安装 / 创建」，它会开始下载游戏本体（几百 MB～1 GB）。
  5. 下载在后台跑；下完回到主界面，版本栏会变成你刚装的版本，点大按钮就开始游戏。

下载慢 / 卡住？ 设置里可以把「游戏下载源」换成镜像；没网时可以先用电脑把 .minecraft 版本的文件夹拷进手机的游戏目录再刷新。

3. 模组怎么装？

方式 A（推荐，最简单）：手动放文件

  1. 主界面菜单里点 「打开游戏文件夹」。
  2. 进 mods 文件夹（没有就新建一个）。
  3. 把电脑上下载的 .jar 模组拷进去（注意：版本要对得上 1.21.1，加载器要对得上 Fabric）。
  4. 回启动器，启动游戏。模组不生效就检查：游戏版本 + 加载器 + 前置模组（Fabric API 等）三样是否都匹配。

游戏文件夹一般在：手机内部存储 Android/data/dev.cubefish.mobile.debug/files 里（拿不到就用「打开游戏文件夹」直接跳转）。

方式 B（启动器内搜索装）：版本栏 → 创建配置 → 选「整合包/模组」那类 → 里面有模组搜索（Modrinth）。这条路引擎原版就有，但入口比较绕，而且部分界面还是英文。

方块鱼 AI 助手目前还不会自动装模组（桌面版会，手机版在下一个版本里做）。

4. 主界面按钮都是干什么的

按钮作用
启动游戏用当前选中的版本启动 Minecraft
版本栏（底部长条）点它选择/安装/管理版本，编辑这个版本的内存、Java、分辨率
Wiki / Discord上游项目文档与聊天群（英文），不用管
自定义控制改游戏里的虚拟按键布局（摇杆、按钮位置）
执行 .jar 文件安装 Fabric/Forge/OptiFine 的安装器 jar（一般用不上）
分享日志文件把日志发给别人看（崩溃求助用）
打开游戏文件夹进到存档/模组/配置所在目录
AI 助手（方块鱼）让方块鱼看日志、改内存、启动游戏——我们这个版本新加的

5. 游戏里操作

  • 屏幕默认有虚拟摇杆 + 按键，可以点右上角齿轮进「自定义控制」改位置和大小。
  • 视角：手指在屏幕空白处拖动；跳跃/潜行/攻击在按钮上。
  • 卡/掉帧：设置 → 视频 → 渲染器换 MobileGlues（默认）或关掉「持续性能模式」试试；内存可以用 AI 助手改成 6–8G。

6. 常见问题

  • 点启动没反应 / 闪退：打开 AI 助手说「看看为什么崩了」，它会读日志给原因。
  • 提示没内存 / 分配过低：AI 助手说「内存调到 8G」，或设置 → Java → 内存分配。
  • 找不到下载的文件：手机「文件管理 → 下载 / Download」目录；小米手机在「文件管理 → 手机 → 下载」。
  • 想装模组包（整合包）：在电脑上装好，再把整个 .minecraft 文件夹通过数据线拷到手机对应目录。

引擎来自 Amethyst / PojavLauncher（Minecraft Java 上手机的移植层），界面部分还是上游的；方块鱼在这上面加了自己的品牌、AI 助手和这份说明。许可证 LGPL-3.0。
